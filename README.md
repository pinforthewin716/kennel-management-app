# Happy Pup Manor — Kennel Management

Repository for the Happy Pup Manor dog boarding / daycare business: the custom
kennel-management application (replacing Gingr + Zoho) and its domain knowledge base.

This is a **separate entity** from the reselling knowledge base (`Happy-Pups/noctowl`),
which holds Amazon/Walmart/eBay reseller documentation. Kennel/Happy Pup Manor
material lives here; reselling material lives there.

## `knowledge/`
Reference docs for running and marketing the boarding facility — Google Business
Profile, local SEO, daycare/boarding operations, pet-care software landscape, and
pet-industry content strategy. Migrated out of the reseller KB on 2026-06-19.
